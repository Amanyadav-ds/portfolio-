# Aman Yadav — Professional Portfolio

A responsive personal portfolio for **Aman Ramashry Yadav**, focused on Data Science, AI, Machine Learning and practical project work.

## Included
- Professional responsive portfolio website
- About, Skills, Projects and Contact sections
- Featured ML projects
- Mobile navigation
- Scroll reveal animations
- Working **Download Resume** buttons
- Resume PDF included at `assets/Aman_Ramashry_Yadav_Resume.pdf`

## Run locally
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing
Replace:
- `https://github.com/` with your GitHub profile/repository URL
- `https://www.linkedin.com/` with your LinkedIn profile URL
- `your-email@example.com` with your real email
- Project `View Project` placeholders in `script.js` with your deployed app/repository URLs

## Deploy
This static site can be deployed on GitHub Pages, Netlify, Vercel, or similar static hosting.
