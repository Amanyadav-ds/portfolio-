# Aman Yadav — Animated Portfolio

A complete responsive animated portfolio built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Customize

1. Replace `your.email@example.com` in `index.html`.
2. Replace the GitHub and LinkedIn placeholder URLs.
3. Update project descriptions/links.
4. Add your resume link if desired.

## Deploy

Upload the folder to GitHub and enable GitHub Pages, or import the repository into Vercel.

No build step is required.
